## Archive Rule

Historical plans, dated audits, one-off QA reports, and superseded architecture notes
belong under `docs/archive/`.

If a doc mainly exists to explain how the code used to work, archive it.
If a doc is dated and not a reusable template, archive it.
If a doc duplicates `architecture/` or `.claude/docs/`, delete or archive it.
