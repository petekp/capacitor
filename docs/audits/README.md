# Audits

This directory is for durable audit artifacts that future sessions should inherit.

Use this directory for:

1. architecture audits
2. migration readiness assessments
3. review packages
4. system analyses that inform future implementation work

Do not use this directory for scratch notes or disposable exploration.

Those belong under local-only `.claude/*`.

Rule of thumb:

1. If the document should shape future repo decisions, keep it here.
2. If the document only helps the current session think, keep it local.
